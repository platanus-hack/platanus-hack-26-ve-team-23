# Requests for Comments

An RFC proposes a change that needs discussion before anyone decides. It
describes the problem and a proposed solution in enough detail for others to
find the holes. An accepted RFC ends in one or more
[ADRs](../adr/README.md).

## Process

1. Copy the template below to `NNNN-short-title.md`, on a branch of its own.
2. Open a draft pull request and ask for comments.
3. Record the alternatives that were rejected and why.
4. Close it as Accepted, merged with the ADRs it produces, or as Withdrawn,
   merged with the reason.

## Template

```markdown
# RFC-NNNN: Title

- **Status:** Draft | Accepted | Withdrawn
- **Author:** name
- **Created:** YYYY-MM-DD

## Problem

## Proposal

## Alternatives

## Dependencies and licences

## Security and privacy

## Open questions
```
